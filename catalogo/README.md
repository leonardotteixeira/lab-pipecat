## Como acrescentar um repo
1. Copie `_modelo.md` para `<nome>.md` e preencha.
2. Se decidir manter uma copia: clone numa pasta ao lado e registre o caminho na tabela.
3. Nunca commite `.env`, chaves ou binarios baixados (o `.gitignore` da raiz cobre isso).
